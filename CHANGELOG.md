# Changelog

All notable changes to **Brackets Refined** will be documented in this file.

## [1.0.2] - 2026-09-06

- Improved CSS numeric value and unit highlighting.
- Refined editor widget colors for better visual consistency.

## [1.0.1] - 2026-09-04

- Updated Python and TypeScript screenshots to reflect the final Brackets Refined theme.

## [1.0.0] - 2026-09-03

### Added

- Initial public release of Brackets Refined.
- Complete Visual Studio Code workbench color palette.
- TextMate syntax highlighting rules.
- Semantic token highlighting.
- Python/Pylance-oriented semantic token fallbacks.
- TypeScript/JavaScript syntax and semantic highlighting refinements.
- Terminal ANSI palette.
- Git, diagnostics, diff, merge, notification, status bar, and symbol icon colors.
