# Support

Use the repository's [GitHub Issues](https://github.com/NeroWolfe75/brackets-refined/issues) to report problems or suggest improvements.

For syntax-highlighting issues, please include:

- Visual Studio Code version
- Language and language extension in use
- A minimal code sample
- Output from **Developer: Inspect Editor Tokens and Scopes**, when relevant
- A screenshot, when it helps demonstrate the visual issue
